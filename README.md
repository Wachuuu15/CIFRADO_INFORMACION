# CIFRADOS 2025


## 📜 Descripción

CIFRADOS 2025 es un repositorio diseñado para implementar cifrados simétricos clásicos como **DES**, **3DES** y **AES** en modos **ECB** y **CBC** utilizando Python y la librería `pycryptodome`. Este proyecto incluye pruebas unitarias y ejemplos de cifrado y descifrado de texto e imágenes.

## ✨ Características

- Implementación de algoritmos de cifrado simétrico: **DES**, **3DES** y **AES**.
- Modos de operación: **ECB** y **CBC**.
- Cifrado y descifrado de mensajes de texto.
- Cifrado y descifrado de imágenes.
- Pruebas unitarias para asegurar el funcionamiento correcto de cada algoritmo.

## 🚀 Instalación y Ejecución

1. Clona este repositorio:

   ```bash
   git clone https://github.com/Wachuuu15/CIFRADO_INFORMACION.git
   cd CIFRADO_INFORMACION
   ```

2. Instala las dependencias necesarias:

   ```bash
   pip install -r requirements.txt
   ```

   > Asegúrate de tener `pycryptodome` y `Pillow` instalados.

3. Ejecuta el script de cifrado y descifrado:

   ```bash
   python cifrado_descifrado.py
   ```

## 📦 Dependencias Principales

Las principales dependencias del proyecto incluyen:

Ejercicio Stream Cipher

📜 Descripción

Ejercicio Stream Cipher es un proyecto que implementa un cifrado de flujo básico utilizando la operación XOR con un generador de keystream pseudoaleatorio (PRNG) en Python. Este ejercicio incluye funciones para generar el keystream, cifrar y descifrar mensajes, así como pruebas unitarias para validar el funcionamiento del sistema.

✨ Características

Generación de keystreams basados en un PRNG inicializado con una semilla específica.

Cifrado de mensajes utilizando la operación XOR.

Descifrado de mensajes utilizando la operación XOR con el mismo keystream.

Pruebas unitarias para validar el cifrado y descifrado correctos.

🚀 Instalación y Ejecución

Clonar este repositorio:

git clone https://github.com/Wachuuu15/Ejercicio_Stream_Cipher.git
cd Ejercicio_Stream_Cipher

Instalar las dependencias necesarias:

pip install -r requirements.txt

Ejecutar el script de cifrado y descifrado:

python Cifrado_XOR_Keystream.py

📦 Dependencias Principales

Python 3.x

📂 Estructura del Proyecto

Cifrado_XOR_Keystream.py: Script principal que contiene la implementación del cifrado y descifrado.

README.md: Documentación del proyecto.
