# CIFRADOS 2025



## ✨ Características

- Comprender el concepto de un keystream y su importancia en los cifrados de flujo.
- Implementar un esquema básico de cifrado y descifrado utilizando XOR.
- Analizar las implicaciones de la reutilización del keystream y su longitud en la seguridad.
  
## 🚀 Instalación y Ejecución

1. Clona este repositorio:

   ```bash
   git clone https://github.com/Wachuuu15/CIFRADO_INFORMACION.git
   cd CIFRADO_INFORMACION
   ```

2. Instala las dependencias necesarias:

   ```bash
   pip install -r requirements.txt
   ```

   > Asegúrate de tener `pycryptodome` y `Pillow` instalados.

3. Ejecuta el script de cifrado y descifrado:

   ```bash
   python cifrado_descifrado.py
   ```

Ejercicio Stream Cipher

📜 Descripción

Ejercicio Stream Cipher es un proyecto que implementa un cifrado de flujo básico utilizando la operación XOR con un generador de keystream pseudoaleatorio (PRNG) en Python. Este ejercicio incluye funciones para generar el keystream, cifrar y descifrar mensajes, así como pruebas unitarias para validar el funcionamiento del sistema.

✨ Características

Generación de keystreams basados en un PRNG inicializado con una semilla específica.

Cifrado de mensajes utilizando la operación XOR.

Descifrado de mensajes utilizando la operación XOR con el mismo keystream.

Pruebas unitarias para validar el cifrado y descifrado correctos.
